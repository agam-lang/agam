# Code of Conduct

Agam is a serious engineering project. Interactions in issues, pull requests, reviews, and related
project spaces are expected to stay constructive and technically grounded.

## Expected Behavior

- critique code and ideas, not people
- be precise, evidence-driven, and respectful
- welcome corrections and review feedback
- assume good faith until behavior shows otherwise
- keep discussions relevant to the repo and the actual change under review

## Unacceptable Behavior

- harassment, insults, or intimidation
- discriminatory or exclusionary language
- repeated bad-faith derailing
- spam, trolling, or attention-seeking disruption
- sharing private or sensitive information without permission

## Enforcement

Project maintainers may moderate discussions, edit or remove inappropriate content, or block
participation when behavior damages the working environment.

For sensitive conduct concerns, use the non-public support path described in [`SUPPORT.md`](./SUPPORT.md).
